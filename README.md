# E-Commerce Customer Segmentation using RFM Analysis

Bu loyiha onlayn do'kon mijozlarini **RFM (Recency, Frequency, Monetary)** tahlili yordamida segmentlarga ajratish va biznes uchun muhim xulosalar chiqarishga bag'ishlangan.

## 🛠 Ishlatilgan vositalar va texnologiyalar
* **Python** (Pandas, NumPy, Seaborn, Matplotlib)
* **SQL** (SQLite orqali ma'lumotlarni so'rovdan o'tkazish)
* **Google Colab** (Ishchi muhit)

## 📊 Loyiha bosqichlari
1. **Data Cleaning (Tozalash):** Xaridor ID-si yo'q va qaytarilgan tovarlar ma'lumotdan olib tashlandi.
2. **RFM Hisob-kitobi:** 
   - **Recency (R):** Mijoz oxirgi marta qachon xarid qilgan?
   - **Frequency (F):** Mijoz jami necha marta xarid qilgan?
   - **Monetary (M):** Mijoz jami qancha pul sarflagan?
3. **Scoring & Segmentation:** Mijozlarga 1-5 gacha ball berilib, ular *VIP, Sodiq mijozlar, Yangi mijozlar va Yo'qolish xavfidagilar* kabi guruhlarga bo'lindi.

## 📈 Asosiy xulosalar (Insaytlar)
* VIP mijozlar kompaniya daromadining asosiy qismini tashkil qiladi.
* Yo'qolish xavfi ostidagi mijozlar uchun maxsus chegirma aksiyalarini tashkil qilish tavsiya etiladi.
